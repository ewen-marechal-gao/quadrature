# ⭐ Caractéristiques

Un personnage dans Quadrature est défini par **10 caractéristiques** réparties sur 2 axes :

|  | Corps | Esprit |
| :---- | :---- | :---- |
| *Puissance* | Force | Volonté |
| *Précision* | Agilité | Intelligence |
| *Résistance* | Vigueur | Ténacité |
| *Expression* | Grâce | Charisme |
| *Sensation* | Acuité | Lucidité |

Chaque **caractéristique est** associée à deux **compétences.** Les deux sont utilisées pour déterminer le nombre de dés à lancer par les joueurs pour effectuer (ou contrer) différentes actions :

✪ **Caractéristique** → le potentiel du personnage (dés 🟦)

**✫ Compétences**   → l'entraînement du personnage (dés 🟨)

Aucune caractéristique n'est supérieure aux autres. Les caractéristiques sont obtenues lors de la création du personnage, puis lors de l'augmentation des **compétences** associées (à chaque rang pair). Les augmentations sont cumulatives, mais une caractéristique ne peut jamais dépasser la valeur de 5\.
