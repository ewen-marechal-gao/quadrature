# 🥷 Furtivité

#### 🌑Occulté

Une case est **occultée🌑** si elle bloque totalement la ligne de vue (mur, colonne), ou se trouve dans une zone offrant une dissimulation visuelle totale (ténèbres, feuillages denses, épais brouillard)

### **Etats**

#### 🤨 Repéré

L'adversaire ignore votre position exacte, mais il a conscience de votre présence. Il ne peut pas vous prendre pour cible. Vous perdez cet état si vous terminez la manche sur une case qui n'est pas **occultée🌑**.

#### 😶‍🌫️Dissimulé

L'adversaire ignore votre présence. Les cibles surprises subissent un **Désavantage 🟥** en défense. Vous devenez **Repéré🤨** immédiatement si :

1. Vous effectuez une action offensive ou sociale.  
2. Vous effectuez un déplacement autre qu'un **Pas 👣** ou une **Furtivité 🥷**.

### **Actions**

**⚠️Défaut sur vos actions furtives :** vous subissez 🟥 à votre prochain jet de **dissimulation** ou **furtivité**.

DD de détection : somme des adversaires à moins de 8 et avec une ligne de vue sur la case occupée ou parcourue par un personnage.

* Les adversaires paniqués ou enragés comptent pour ½ (arrondir au supérieur)  
* Les adversaires avec au moins un dé 🟫 comptent pour 2  
* Les adversaires avec le mot clé **télépathe** comptent pour 3

2️⃣😶‍🌫️ Dissimulation

**Coût :** 🟢  
🔒**Condition :** vous occupez une case **occultée🌑**  
🎲**Jet :** Mascarade🟨🟨 \+ Grâce🟦  
🆚**Contre Personnages :** Acuité🟨🟨 \+ Observation🟦  
🆚**Contre Adversaires :** DD de détection.

✴️**Critique :** vous bénéficiez de 🟩 sur votre prochaine **furtivité**  
✅ **Succès :** vous êtes **Dissimulé**😶‍🌫️					❌ **Échec :**  vous êtes **Repéré**🤨

#### **6️⃣**🥷 Furtivité

**Coût :** **⚫**  
🔒**Condition :** Le personnage doit être **Dissimulé**😶‍🌫️ et terminer son mouvement sur une case **occultée🌑**  
🎲**Jet :** Mascarade🟨🟨 \+ Grâce🟦  
	**⛞ Course furtive :**  **↗️1**💧afin de parcourir une distance de **deux** cases supplémentaires.  
🆚**Contre Personnages :** Acuité🟨🟨 \+ Observation🟦  
🆚**Contre Adversaires :** DD de détection.

➡️**Inertie 2 :**: Le personnage se déplace en marchant de **trois** cases.

✴️**Critique :** vous bénéficiez de 🟩 sur votre prochaine **dissimulation**  
✅ **Succès :** vous restez **Dissimulé**😶‍🌫️					❌ **Échec :**  vous êtes **Repéré**🤨
